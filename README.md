# REPOSITORIO FOCADO EM ENTENDER MAIS A FUNDO NA PRATICA SOBRE GIT

### o que ja sei:
- git init
- git remote add origin https://github.com/joaofantindev/....
- branch -M nome
- git add . (adiciona todos os arquivos da raiz)

- git status -> tracking de arquivos sendo criados/modificados...gerais
- git commit -m "commit de modificiações" -> salva cada passo de avanço no sistema
- git log -> autor do commit, quando foi, mensagem, hash do commit (avançado: fazer modificações no commit por aqui)
- git branch -> branchs ativos
- git push -f/-u origin branch
