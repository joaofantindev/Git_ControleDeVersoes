GIT VERSÃO

O que é
Git é um sistema de controle de versão distribuído. Rápido, direto e feito para acompanhar cada alteração do seu código com precisão.
Conceitos Fundamentais
01

Commit

Um registro imutável de alterações. Um ponto no histórico com mensagem clara.

02

Branch

Uma linha paralela de desenvolvimento. Trabalhe isolado sem afetar a principal.

03

Merge

Integração de alterações. Junta uma branch de volta à linha principal.

04

Push / Pull

Sincronização com repositório remoto. Compartilhe e atualize seu histórico.
